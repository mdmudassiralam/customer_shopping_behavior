# 📊 Data Analytics Project

## 📌 Project Overview

This project demonstrates an **end-to-end data analytics workflow**, starting from raw dataset exploration and data cleaning to SQL-based analysis and interactive dashboard development using Power BI.

The project combines **Python, MySQL, and Power BI** to transform raw data into meaningful insights and support data-driven decision-making.

### 🔄 Project Workflow

`Dataset` → `Python` → `EDA` → `Data Cleaning` → `MySQL` → `SQL Analysis` → `Power BI Dashboard` → `Insights`

## 🐍 1. Data Loading & Exploration

The dataset was first loaded into Python using **Pandas**.

The initial analysis focused on understanding:

* Dataset dimensions
* Column names
* Data types
* Missing values
* Duplicate records
* Descriptive statistics
* Unique values

## 🔎 2. Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed to understand patterns, trends, relationships, and anomalies within the dataset.

The analysis included:

* Univariate analysis
* Bivariate analysis
* Distribution analysis
* Correlation analysis
* Outlier detection
* Category-wise analysis
* Trend analysis


---

## 🧹 3. Data Cleaning

The dataset was cleaned and prepared for further analysis.

The main data-cleaning steps included:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Cleaning inconsistent values
* Standardizing categorical data
* Renaming columns where required
* Handling outliers
* Creating required calculated columns



## 🗄️ 4. MySQL & SQL Analysis

The cleaned dataset was imported into **MySQL Workbench** for structured data analysis.

SQL queries were written to answer important business questions and extract meaningful insights from the data.

### SQL Concepts Used

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* `HAVING`
* Aggregate Functions
* `CASE WHEN`
* Subqueries
* `JOIN`
* CTEs
* Window Functions



## 📊 5. Power BI Dashboard

The analyzed data was then used to build an **interactive Power BI dashboard**.

The dashboard provides a visual representation of important KPIs, trends, and performance indicators.

### Dashboard Features

* 📌 KPI Cards
* 📈 Trend Analysis
* 📊 Bar Charts
* 🍩 Donut Charts
* 📋 Tables
* 🎛️ Interactive Slicers
* 🔍 Filters
* 📊 Category-wise Analysis
* 📅 Time-based Analysis
